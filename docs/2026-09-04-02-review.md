## 1. Bugs de logique

### 1.1 `order: "reverse"` inopérant sans `loop`

- `Diaporama.jsx:70` : `currentIndex` initialisé à `0` ; idem au reset (`:104`) et dans `enterDirectory` (`:185`).
- `goNext` en reverse (`:149`) : `prev === 0` → reste à `0` si `loop` est `false`.
- Effet : autoplay et flèche droite ne font rien en mode reverse.
- Correction : index de départ `children.length - 1` quand `order === "reverse"` (3 endroits).

### 1.2 Index qui dérive dans un dossier vide

- `goNext` (`:151`) : avec `len === 0`, `prev === len - 1` est faux → `currentIndex` devient 1, 2, 3…
- Le compteur masque le problème (`:484`) mais l'état est incohérent.
- Correction : `if (len === 0) return prev;` dans `goNext` et `goPrev`.

### 1.3 Offset non re-borné au dézoom

- Touches `2`–`9` (`:234-249`), `-` (`:230`), molette (`:263`) modifient `scale` sans re-clamper `offset`.
- Borne = `renderedWidth * scale / 2` : un pan à 9× puis passage à 2× laisse l'image hors écran.
- Correction : re-clamper `offset` dans un effet dépendant de `scale` (ou dans chaque setter).

### 1.4 `e.preventDefault()` inopérant dans `onWheel`

- `Diaporama.jsx:261`. React ≥ 17 enregistre `wheel` en listener passif : appel ignoré + warning Chrome.
- Déjà relevé au log 001, non corrigé. Sans effet visible grâce à `overflow: hidden`.
- Correction : retirer l'appel, ou listener natif `{ passive: false }` via ref si le blocage est requis.

## 2. Robustesse / edge cases

### 2.1 Un fichier illisible fait échouer tout le dossier

- `readDirectory.js:39` : `entry.file(resolve, reject)` dans un `Promise.all` → un seul rejet annule la lecture complète.
- L'erreur est loggée (`DropZone.jsx:38`, `Diaporama.jsx:187`) mais le dossier ne s'ouvre pas.
- Correction : résoudre `null` en cas d'erreur pour ignorer le fichier fautif.

### 2.2 Race `enterDirectory` vs. nouveau drop

- `Diaporama.jsx:179-185` : si un nouveau dossier est déposé pendant l'`await`, le reset (`:101`) s'exécute puis la promesse écrase `currentDirectory` avec un sous-dossier de l'ancienne racine.
- Complémentaire à la correction du log 003 (double Enter).
- Correction : ref sur la racine courante, abandon si `directory` a changé après l'`await`.

### 2.3 `renderedSizeRef` obsolète

- `Diaporama.jsx:380-387` : mis à jour uniquement au `onLoad`.
- Entre changement d'image et chargement, et après resize fenêtre, le clamp utilise les dimensions précédentes.
- Correction : `null` au changement d'item (fallback `innerWidth/2` existant) + écoute `resize`.

### 2.4 Touche Espace avec `<video controls>` ou bouton play focalisé

- `:250-253` : le `keydown` global bascule `playing` tandis que l'élément natif bascule aussi sa propre lecture / déclenche son click.
- Correction : ignorer si `e.target` est `button`/`video`, ou ne pas laisser le focus dessus.

### 2.5 Raccourcis sans filtre de modificateurs

- `a`, `z`, `h`, `0-9`, `+/-` réagissent aussi à `Cmd+A`, `Cmd+-`, etc.
- Correction : `if (e.metaKey || e.ctrlKey || e.altKey) return;` en tête de `handleKeyDown`.

## 3. Qualité / UX mineurs

- **Tri non numérique** — `readDirectory.js:50` : `img10.jpg` avant `img2.jpg`. → `localeCompare(b.name, undefined, { numeric: true })`.
- **« Fichier créé le » = date de modification** — `Diaporama.jsx:310` (`fileCreated = fileModified`). Le navigateur ne fournit pas la date de création : supprimer ou renommer la ligne.
- **Zoom clavier asymétrique** — `+` → `* 1.1` (`:228`), `-` → `- 0.1` (`:230`). → `prev / 1.1`.
- **Flicker `dragActive`** — `dragleave` sur `window` (`DropZone.jsx:51`) et conteneur (`:17`) déclenché au survol des enfants. Cosmétique.
- **`console.log` de debug** — `App.jsx:11`.
- **`readAllEntries` exporté mais utilisé uniquement en interne** — `readDirectory.js:3`. Non bloquant.
